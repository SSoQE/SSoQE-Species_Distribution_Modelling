# Repository-specific guidance

This is a mixed legacy R and Quarto repository for Species Distribution Modelling.

- Preserve the established root-level Quarto and PDF materials; do not migrate them into the current lecture template without a separate request.
- Treat the 2025 source filenames as historical teaching identifiers. Renaming those teaching files and repairing their references requires a separate source migration and render.
- The root R project file follows the final 2026 repository identity.
